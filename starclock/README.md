# Civitatum Starclock 0.1.0 — M1

Модуль набора Civitatum RP Addons для Minecraft 1.21.1, NeoForge 21.1.256 и Java 21.
Лицензия MIT. Обязательная зависимость: GeckoLib 4.8.4 или совместимая версия 4.x.

## Возможности этой версии

- Двенадцать инструментов: четыре вида по три ступени.
- Отдельная творческая вкладка и рецепты всех ступеней.
- Ключ Башни: пять открываний закрытой железной двери или железного люка.
- Серверный обряд: 40 тиков подготовки и 40 тиков вытягивания.
- Равновероятный выбор из 13 фигур; два положения обычных знаков; у Змея положения нет.
- Статическая карта с именем, положением, значением и ступенью.
- Общий кулдаун 192 000 тиков в SavedData оверворлда, сохраняемый вместе с миром.
- Оригинальные спрайты инструментов и ключа, воспроизводимые генератором.

Карта M1 показывает значение фигуры. Эта версия не исполняет отложенные события.
Очередь и события относятся к M2, анимации GeckoLib и совместимость с Punchy — к M3,
рисованные фигуры и звук — к M4, конфиг и команды — к M5.

## Сборка

Потребуются Java 21, Python 3.10+ с модулем venv и доступ к Maven/PyPI при первой сборке.
Gradle создаёт отдельное Python-окружение внутри `starclock/build` и устанавливает Pillow 11.3.0.
Системное Python-окружение не изменяется.

Из корня набора:

```sh
./gradlew :starclock:generateTextures :starclock:test :starclock:build
```

Windows PowerShell:

```powershell
.\gradlew.bat :starclock:generateTextures :starclock:test :starclock:build
```

Если Python имеет другое имя:

```sh
./gradlew :starclock:build -PstarclockPython=/absolute/path/to/python3
```

Jar: `starclock/build/libs/civitatum-starclock-0.1.0.jar`.
Сгенерированные PNG находятся в `starclock/build/generated/starclockResources` и включаются в jar автоматически.
Отдельный набор исходников `tools` не попадает в jar.

Запуск для разработки:

```sh
./gradlew :starclock:runClient
./gradlew :starclock:runServer
```

Для локальной установки укажите `instanceDir` в пользовательском `~/.gradle/gradle.properties`,
затем выполните `./gradlew :starclock:installToInstance`. Игра должна быть закрыта.

## Управление

Возьмите инструмент в любую руку. В ясную ночь Верхнего мира выйдите под открытое небо,
поднимите взгляд минимум на 35° над горизонтом и удерживайте кнопку использования 40 тиков.
Следующие 40 тиков отведены вытягиванию. В конце откроется карта.

Отпускание кнопки во время подготовки, смена инструмента, полученный урон, смерть,
выход из игры или смена измерения прерывают незавершённый обряд без кулдауна.
Взгляд, погода, видимость неба и время проверяются до завершения вытягивания.
Во время вытягивания удерживать кнопку уже не требуется.
Двигаться разрешено, пока сохраняются условия обряда.
Одновременно в мире может идти только один обряд.

Обряд доступен при времени суток 13000–23000 включительно.
Кулдаун считается по времени работы мира, не по часам компьютера.
Сон и `/time set` не сокращают его. При штатном сохранении и перезапуске остаток сохраняется.
Незавершённый обряд после перезапуска нужно начать заново.

Ключ используется правой кнопкой по закрытой железной двери или люку.
По уже открытой двери применение не тратится. В творческом режиме износ подчиняется ванильным правилам.

## Рецепты

Рецепты I и II ступеней бесформенные.

| Инструмент | I ступень |
|---|---|
| Колода | 3 бумаги, золотой слиток, осколок аметиста |
| Секстант | Подзорная труба, 2 медных слитка, осколок аметиста |
| Чаша | Миска, ведро воды, осколок аметиста; пустое ведро возвращается |
| Кольцо | Золотой слиток, осколок аметиста |

II ступень: инструмент I ступени, 4 осколка аметиста и золотой блок.
III ступень: на кузнечном столе эхо-осколок в слоте шаблона,
инструмент II ступени в слоте основы, незеритовый слиток в слоте добавки.
Эхо-осколок расходуется. У ключа рецепта нет: в M1 он доступен из творческой вкладки.

## Проверка в игре

1. Запустите клиент, проверьте вкладку, 12 инструментов и ключ. Ресурсы должны загрузиться без отсутствующих текстур.
2. Для быстрого теста используйте `/time set 14000` и `/weather clear`.
3. Начните подготовку и отпустите кнопку: карта не открывается, повторная попытка доступна.
4. Повторите, сменив инструмент, опустив взгляд или получив урон.
5. Завершите обряд: через 80 серверных тиков появляется карта.
6. Второй игрок должен получать сообщение о занятом обряде или общем кулдауне.
7. Сохраните мир и перезапустите сервер: сообщение о кулдауне должно сохраниться.
8. В отдельном тестовом мире проверьте ключ на обоих блоках и его исчезновение после пяти применений в выживании.
9. Отдельно запустите выделенный сервер: клиентские экраны не должны загружаться на сервере.

Время в реальных секундах зависит от TPS. При 20 TPS каждая фаза занимает две секунды.

## Ограничения M1

Карты ещё не содержат иллюстраций созвездий и подробностей будущего события.
Иммерсивный рендер, блокировка ввода, очередь, торговцы, вебхук и диагностические команды
не входят в эту версию. Файл конфигурации миксинов содержит только общие параметры,
поскольку M1 не перехватывает рендер и ввод.
Мод необходим на сервере и на клиенте; `displayTest` не заменяет сетевую совместимость.

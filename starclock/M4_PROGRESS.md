# Контрольная точка M4

Основа: M3, коммит `208670ddb5ecd5be97850f6121cb26ed39a33e77`.
Рабочая ветка: `codex/starclock-m4`.

## Подготовленный блок

- Восемь оригинальных звуков и полный генератор PCM → Ogg Vorbis.
- Автоматическая генерация при сборке; кодировщик поставляется закреплённой зависимостью Python.
- Регистрация SoundEvent, sounds.json, русские и английские субтитры.
- Звуковые ключевые кадры четырёх инструментов.
- Звуки начала вытягивания и открытия карты; Змей не раскрывает выбранное событие.
- Проверка повторяемости байтов, реальное декодирование, проверки ссылок ресурсов и загрузки в клиенте.

Команды и состав звуков: `SOUNDS.md`. Результаты конкретного коммита хранятся в GitHub Actions.
Эта контрольная точка не означает завершение всего M4.

## Что блокирует художественную часть

Архив `ПнВ - созвездия(2).zip` найден среди приложений, размер 23 352 508 байт.
Содержимое ZIP нельзя прочитать текстовым просмотром; локальная среда выполнения недоступна.
Изображения из архива не просмотрены и не заменялись выдуманными фигурами.

Для продолжения достаточно загрузить исходный ZIP в эту ветку репозитория, например
в `starclock/art/source/constellations.zip`. Подойдёт и папка с распакованными оригинальными PNG.
После получения доступных изображений можно подготовить 13 фигур, уробороса,
окончательные карты, экран прорисовки и оставшиеся элементы интерфейса.

## Ограничение использования

Пользователь попросил сохранять прогресс и останавливаться при остатке 10% лимита использования.
Доступа к счётчику лимита в этой сессии нет, поэтому определить достижение порога невозможно.
Прогресс фиксируется в Git законченными блоками.

# Текстуры Civitatum Starclock

Авторский код генераторов и нарисованные ими спрайты и рамки — MIT. Созвездия подготовлены из архива, предоставленного автором проекта; лицензия исходных рисунков в архиве отдельно не указана. Их происхождение не подменяется лицензией кода.

Генератор: `tools/generate_textures.py`, Python 3.10+ и Pillow 11.3.0. Вывод детерминированный: не зависит от времени и случайного состояния. Для фигур требуется сохранённый в репозитории `starsigns.zip`. Скрипт `generate_art.py` извлекает цветные линии оригиналов, убирает фон, сохраняет пропорции и переводит линии в палитру мода.

Команда: `./gradlew :starclock:generateTextures`. Каталог вывода: `starclock/build/generated/starclockResources/assets/starclock/textures/`. Сборка автоматически включает его в jar.

Атласы: четыре материала по 16×16 в полосе y=0…15; орнамент рубашки/воды x=0…23, y=16…55; лицо малой карты x=32…55, y=16…55. Все кубы имеют явные UV в границах атласа. Четыре инструмента используют собственные `geo/*.geo.json` и `animations/*.animation.json`.

Руки отрисовываются ванильным PlayerRenderer со скином и рукавами текущего игрока, включая узкую модель Alex. Скин игрока не включается в ресурсы мода. Звуковые ключи используют восемь зарегистрированных звуков M4; описание — в `SOUNDS.md`.

Фигуры имеют прозрачный фон. Поворот перевёрнутого знака применяется только к рисунку;
текст и рамка остаются читаемыми. Змей использует отдельную карту, рисунок не поворачивается.
Искры интерфейса рисуются напрямую из PNG; отдельный зарегистрированный тип частицы для них не нужен.
Мировые частицы GeckoLib продолжают использовать ванильную пыль цвета палитры.

`starclock-art.json` рядом с каталогом assets содержит SHA-256 архива, исходных PNG и область обрезки.
При отсутствии любого оригинала генератор завершает сборку с ошибкой.
`tools/test_art.py` дважды строит графику и сравнивает каждый байт.

# Текстуры Civitatum Starclock

Все изображения оригинальные, MIT. Генератор: `tools/generate_textures.py`, Python 3.10+ и Pillow 11.3.0. Вывод детерминированный: без случайных чисел, времени и внешних изображений.

Команда: `./gradlew :starclock:generateTextures`. Каталог вывода: `starclock/build/generated/starclockResources/assets/starclock/textures/`. Сборка автоматически включает его в jar.

| Файл относительно каталога текстур | Размер | Использование |
| --- | --- | --- |
| `item/deck_1.png`, `deck_2.png`, `deck_3.png` | 16×16 | Колоды, инвентарь и обычный предмет в руке |
| `item/sextant_1.png`, `sextant_2.png`, `sextant_3.png` | 16×16 | Секстанты трёх ступеней |
| `item/bowl_1.png`, `bowl_2.png`, `bowl_3.png` | 16×16 | Чаши трёх ступеней |
| `item/ring_1.png`, `ring_2.png`, `ring_3.png` | 16×16 | Кольца трёх ступеней |
| `item/tower_key.png` | 16×16 | Значок способности в меню Civitatum Inventory; совместимость со старым предметом |
| `model/deck.png` | 64×64 | Две половины колоды и отдельная переворачиваемая карта |
| `model/sextant.png` | 64×64 | Дуга, индекс, линза и блик секстанта |
| `model/bowl.png` | 64×64 | Стенки чаши, вода, отражение фигуры, рябь |
| `model/ring.png` | 64×64 | Обод, двенадцать насечек, аметист и блик |

Атласы: четыре материала по 16×16 в полосе y=0…15; орнамент рубашки/воды x=0…23, y=16…55; лицо малой карты x=32…55, y=16…55. Все кубы имеют явные UV в границах атласа. Четыре инструмента используют собственные `geo/*.geo.json` и `animations/*.animation.json`.

Руки отрисовываются ванильным PlayerRenderer со скином и рукавами текущего игрока, включая узкую модель Alex. Скин игрока не включается в ресурсы мода. Звуковые ключи M3 используют зарегистрированные ванильные звуки; частицы — ванильную пыль с цветами палитры.

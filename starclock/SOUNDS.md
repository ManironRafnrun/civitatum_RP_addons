# Звуки Civitatum Starclock

Все восемь звуков синтезируются оригинальным кодом `tools/generate_sounds.py`, MIT.
Готовые чужие записи и ассеты не используются.

| Событие | Длительность | Звучание | Где используется |
| --- | --- | --- | --- |
| shuffle | 0,28 с | Три коротких бумажных шороха | Тасование колоды |
| sextant_click | 0,18 с | Металлический щелчок с коротким резонансом | Настройка секстанта |
| water_pour | 0,70 с | Плеск с четырьмя затухающими каплями | Чаша ночи |
| ring_hum | 0,75 с | Мягкий тон с обертонами и модуляцией | Вращение кольца |
| stars_reveal | 1,20 с | Восходящий перезвон | Начало вытягивания |
| card_flip | 0,24 с | Шорох переворота с коротким щелчком | Карта колоды и открытие экрана карты |
| omen_good | 1,35 с | Светлый разрешающийся аккорд | Карта обычного знака в прямом положении |
| omen_bad | 1,35 с | Низкий неустойчивый аккорд | Карта обычного знака в перевёрнутом положении |

Змей использует только нейтральный звук переворота: благоприятность выбранного события
не передаётся клиенту и не раскрывается звуком.

Формат: Ogg Vorbis, один канал, 44 100 Гц. Выход:
`starclock/build/generated/starclockAudio/assets/starclock/sounds/ritual/*.ogg`.
Регистрация: `ModSounds`; определения и субтитры:
`assets/civitatum_starclock/sounds.json`, `ru_ru.json`, `en_us.json`.

## Генерация

```sh
./gradlew :starclock:generateSounds
```

Задачи `processResources` и `build` вызывают генерацию автоматически.
Python-окружение устанавливает `imageio-ffmpeg==0.6.0` с готовым FFmpeg для платформы;
ручная установка кодировщика не требуется на поддерживаемых платформах.
При необходимости путь к совместимому FFmpeg задаётся переменной `IMAGEIO_FFMPEG_EXE`.

PCM синтезируется с фиксированными начальными состояниями шумового генератора.
Кодировщик запускается без переменных метаданных; серийные номера Ogg фиксируются,
CRC страниц пересчитываются. Одинаковый кодировщик выдаёт одинаковые байты при повторном запуске.
Смена версии или сборки кодировщика может изменить сжатые байты.

## Проверка

```sh
./gradlew :starclock:build :starclock:test
starclock/build/texture-python/bin/python starclock/tools/test_sounds.py
```

Python-проверка генерирует каждый файл дважды и сравнивает байты, декодирует его настоящим
кодировщиком, проверяет длительность, отсутствие клиппинга и тишины, уровень сигнала и края.
JUnit проверяет ссылки анимаций, существование Ogg, заголовки Vorbis и субтитры.
Тестовый клиент загружает все восемь событий и воспроизводит файлы через SoundManager.
Обычный звук анимации воспроизводится по ключевым кадрам GeckoLib; устаревшие кадры пропускаются.

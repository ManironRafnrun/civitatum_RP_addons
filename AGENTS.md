# CCI: разработка и сохранение

Проект: Civitatum Couple Interaction (CCI), Minecraft 1.21.1 / NeoForge. Исходный прототип восстановлен из предыдущего рабочего диалога; не удалять его историю.

Во время активной работы сохранять исходники в Git каждые 600 секунд: `python3 -u tools/git_checkpoint.py watch`. Перед изменениями и завершением выполнить `once`, дождаться `REMOTE_VERIFIED`; успех проверяется по точному дереву файлов. Не реже раза в пять минут продлевать активность командой `heartbeat`. В конце выполнить `stop` и дождаться остановки таймера.

Резервные снимки CCI: `codex/checkpoints/cci` в подключённом репозитории ManironRafnrun/civitatum_RP_addons. Код и выпуски CI в своих ветках не изменять. Проверенный CCI сохранять отдельной веткой выпуска. Не изменять `main`, не использовать force push и не переставлять выпущенные метки.

Тестовые классы `src/smoke` и `src/test`, миры, конфиги запуска и скачанные зависимости не должны попадать в выпускаемый JAR. Не сохранять данные авторизации и SDK в исходниках. Новый SDK текущей сессии и приватные настройки подключения размещать вне Git-дерева.

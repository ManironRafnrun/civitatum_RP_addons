# Сохранение CCI

Удалённый Git: https://github.com/ManironRafnrun/civitatum_inventory.git. CCI имеет самостоятельное дерево исходников в отдельной ветке `codex/checkpoints/cci`. Ветки CI не изменяются при сохранении CCI.

Перед изменениями: `python3 tools/git_checkpoint.py once`, дождаться `REMOTE_VERIFIED`. При активной работе: `python3 -u tools/git_checkpoint.py watch`. Интервал — 600 секунд; пустых коммитов нет. Не реже раза в пять минут выполнять `heartbeat`; разрешение таймера истекает через 20 минут без активности. Перед завершением снова выполнить `once`, проверить `status`, затем `stop` и дождаться остановки процесса.

Серверное дерево проверяется на точное совпадение с локальным. При записи через GitHub connector SHA коммитов отличается; локальный SHA и хеш дерева указаны в сообщении серверного коммита. В приватном `.git/civitatum-backup/github-config.json` находятся параметры подключения и путь к свежему SDK текущей сессии вне репозитория. Авторизацию, SDK, сборочные кэши, миры и скачанные моды в Git не добавлять. Обычная HTTPS-авторизация Git позволяет обходиться без этого конфига.

Проверенные исходники сохраняются отдельной веткой выпуска `codex/cci/releases/0.1.0-alpha.3`. Исходный прототип и проверенный выпуск имеют отдельные локальные метки; полная история с ними сохраняется bundle в ветке `codex/cci/history/0.1.0-alpha.3`. Ветки выпуска и истории alpha.2 сохранены отдельно. Не передвигать выпущенные метки и не применять force push.

Таймер работает только в живой рабочей сессии. После удаления или восстановления среды его необходимо запустить заново. Правила продолжения закреплены в `AGENTS.md`.

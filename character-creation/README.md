# Civitatum Character Creation 0.5.0

Minecraft **1.21.1** · NeoForge **21.1.256+** (ветка 21.1) · Java **21** · **Civitatum Team**

Единый редактор расы и внешности с предпросмотром в игровом мире.

Установите одинаковый `civitatum-character-creation-0.5.0.jar` на сервер и все клиенты, заменив предыдущий JAR CCC: клиент и сервер должны использовать одну версию мода (сетевой протокол 3). ID мода `civitatum` сохранён: персонажи 0.2.0–0.4.1 продолжают загружаться, новые поля получают значения по умолчанию.

## Новое в 0.5.0: народы и небо

Способности рас и знаки рождения заменены целиком по документу «10b. Народы и небо» (способности по `14`, знаки по `15`). Сверено с NeoForge 21.1.256; цели всех миксинов проверены по байткоду.

**Что было.** Способности рас из первого прототипа не совпадали с каноном ни у одной из 18 рас, ценой силы была еда или мана Ars Nouveau с откатом 25–100 с, знаки рождения были шестью шаблонами TES (Воин, Маг, Вор…), которых нет в каноне.

**Что сделано.**
- У каждой расы три слоя из документа: тело, место и сила. Полный список — в [RACES.md](RACES.md).
- **Сила расы — раз в игровые сутки** (откат 1200 с); еда и мана не тратятся. Платят эффектом после силы: «Отходняк» после «Ярости», «Хрип» после «Выдоха», «Последствие» после «Маски», Слабость после «Замены». Эффект-расплата наступает и тогда, когда силу сняли молоком.
- Сила с несколькими частями — **один эффект с одним значком** (`civitatum:rage`, `civitatum:mask` и другие, всего 19): атрибуты внутри эффекта, числа как у ванильных эффектов (Сила II = +6 урона, Замедление I = −15%). Иконки берутся из ванильных через атлас `assets/minecraft/atlases/mob_effects.json`, своих картинок нет.
- **Пассивы рас — без частиц**: это модификаторы атрибутов, а эффекты (ночное зрение, «Подземный», Слабость нежити у Пастыря) выдаются без частиц; ночное зрение — ещё и без значка.
- «Транс» лесного эльфа и «Выдох» огненного драконита работают, пока держишь клавишу; отпустил — сила заканчивается раньше.
- Блоки сил (цепь дварфа, корни, паутина, лёд, колокол гоблина, костёр Очага) временные: снимаются сами, переживают перезапуск сервера и ничего не роняют ни при ломании, ни при взрыве.
- Расы переименованы по канону: Механист, Турс, Кайри, Борянин, дракониты; Эндер-драконит в интерфейсе — «Краевой драконит». ID рас не менялись, персонажи загружаются.
- Убрано то, чего нет в каноне: питание механиста металлами, мана Ars Nouveau, огненная смерть кайри, бонус опыта человеку и городскому альгнору. Запрет ботинок у хоббита и борян оставлен: он описан в облике народов.
- **Знаки рождения — тринадцать фигур** с ID Starclock: Башня, Копьё, Очаг, Зверь, Матерь, Кузнец, Купец, Пряха, Гонец, Пращур, Пастырь, Странник, Змей. У Стражей (Копьё, Кузнец, Гонец) только пассив; у Покровителей — пассив, цена и сила; сила знака — на **отдельной клавише G**. «Отсрочка» Пращура срабатывает сама, раз в сутки.
- Знак даётся персонажу навсегда. В редакторе выбирают месяц или «Бросить жребий»: жребий тянет сервер при сохранении, с шансом 1 к 20 выпадает Змей. Иначе Змея выдаёт только администратор: `/civitatum sign set <игрок> serpent`.
- «Переписать небо»: `/civitatum sign rewrite` — раз за персонажа, ночью, за один уровень опыта; знак сбрасывается, открывается редактор, до рассвета нельзя уснуть.
- Старые знаки TES при загрузке становятся «без знака»; игроку при входе приходит напоминание выбрать знак (`/civitatum race looks`).
- «Звёздный свет» астрального эльфа светит через LambDynamicLights (необязательная зависимость, только на клиенте). Это свет клиента: мобы спавнятся по свету сервера.
- «Эндер-слух» краевого драконита подсвечивает эндерменов и шалкеров только у него на экране.

**Союзники.** Силы, которые действуют «на союзников» («Набат», «Доля», «Разжечь»), касаются самого игрока и игроков его команды (ванильная команда или FTB Teams); остальные игроки рядом считаются чужими.

**Совместимость, проверенная в сборке.** «Отсрочка» Пращура срабатывает раньше нокаута Hardcore Revival (тот ловит смерть с приоритетом High); тотем бессмертия по-прежнему срабатывает первым. Пауки Spider Overhaul не нападают на тёмного эльфа первыми, их эффект «Паутина» на него не действует. Corpse не возвращает опыт, поэтому «Тетрадь» механиста не удваивается; ванильные шары опыта при смерти падают как обычно. Союзники из отряда FTB Teams получают «Набат» и «Долю», посторонние игроки — нет. Ключ Башни знака и Ключ Башни Starclock у одного игрока независимы: знак не тратит заряды Starclock, заряд Starclock не трогает откат знака. Шаг Гонца поднимает на блок при обычной ходьбе вместе с ParCool и Better Combat. «Укус» Змея работает и на разбойников Villagers Reborn. Урон сил по мобам с бронёй меньше номинала из-за брони (формула Apothic Attributes), магический урон «Укуса» проходит полностью.

**Как решены споры из части V документа** (по предложениям документа): сила Пастыря — «Перекличка»; Кузнец и дварф/гоблин на наковальне перемножаются (×0,5 × 0,75); «крафт дешевле» гоблина — наковальня −25% и шанс 25% вернуть ингредиент; у «Маски» числа из `14` (15 с, +2 урона); подрасы борян оставлены как варианты внешности с одинаковыми способностями.

**Чего нет.** Замки Supplementaries Ключ Башни не открывает (только двери, люки и контейнеры с ванильным замком). Поводок Пряхи — только на мобов: игрока в ванили на поводок не взять. Приручение с первого раза — у волка, кошки, попугая и лошадей; у животных других модов шанс прежний. «Травник» срабатывает при ломании растений, сбор ягод правым кликом не учитывается. «Алхимик» удлиняет только выпитые зелья, не взрывные и не туманные. Зона «Запечатать» живёт в памяти: после перезапуска сервера защита от спавна пропадает раньше срока (цепь тоже снимается).

Миксины обязательные: если после обновления Minecraft или NeoForge их цель не найдётся, игра упадёт при запуске с ошибкой Mixin, а не будет молча работать без способностей.

## Новое в 0.4.2

- Добавлены **28 разных причёсок** из архива CCC Haircuts 1.0.0. Вместе с прежними 13 в каталоге теперь **41** вариант. Повтор исходного Hair Base уже объединён в предоставленном каталоге.
- Сохраняются исходный рисунок, UV и прозрачность. Девять подготовленных плавных переходов читаются как веса смешивания, а не как резкие бинарные маски.
- Для десяти одноцветных причёсок дополнительно выделены тени и более тёмные пряди. Созданы отдельные служебные карты; предоставленные PNG не менялись.
- Режим **«Оттенки от цвета волос»** связывает дополнительный тон с выбранным основным цветом. Можно выбрать глубокую тень, тёмный, приглушённый или светлый оттенок того же цвета. «Исходный» сохраняет соотношение тонов исходной причёски. Смена основного цвета сразу меняет связанные оттенки.
- Режим можно выключить для независимого выбора цветов омбре. Украшения, завязки, венки и заколки всегда сохраняют собственные цветовые поля. Многоцветная Celestial также имеет независимые поля.
- Все поля в исходном состоянии восстанавливают точные пиксели исходной причёски. Неиспользуемые цветовые поля не показываются. Палитры с девятью цветами размещаются в два ряда внутри окна.
- **Пять текстурных бород и пять вариантов усов**, выбираемых отдельно. Старые объёмные элементы бород убраны. Цвет связан с основным цветом волос. Более длинные бороды продолжаются по UV груди, как длинные пряди волос.
- Бороды и усы доступны мужчинам тех рас, у которых это разрешено. **Из женщин — только дварфам.** Правило одинаково в интерфейсе, предпросмотре и серверной проверке сохранения.
- Рост виден **до подтверждения**: размер модели больше не компенсируется автоматическим подгоном. При полном виде используется общий масштаб, рядом есть линейка и числовое значение.

## Управление

| Действие | Команда / клавиша |
|---|---|
| Выбрать расу и создать персонажа | `/civitatum race choose` |
| Изменить всё, кроме расы | `/civitatum race looks` |
| Косметический редактор | ПКМ Зеркалом преображения / Осколком Демитары либо F6 с предметом |
| Показать только нижнее бельё | `/civitatum race naked true` |
| Вернуть декоративную одежду | `/civitatum race naked false` |
| Сила расы | R (держать — для «Транса» и «Выдоха»), переназначается в управлении |
| Сила знака рождения | G, переназначается в управлении |
| Метка Тропы (Странник) | Shift + G |
| Выдать знак, в том числе Змея (оператор) | `/civitatum sign set <игрок> <знак>` |
| Переписать небо (раз за персонажа, ночью) | `/civitatum sign rewrite` |
| Зеркало преображения | `/give @s civitatum:appearance_mirror` |
| Осколок Демитары | `/give @s civitatum:demitara_shard` |
| Сбросить расу и внешность | `/civitatum race reload` |
| Перечитать конфиг | `/civitatum configreload` |

Команды `choose` и `looks` принимают имя другого игрока последним аргументом (для операторов). Старое написание `races choose` заменено на `race choose`.

Командный редактор `looks` меняет всё, кроме расы, в том числе пол и тело. Знак рождения в нём выбирается, только если его ещё нет.

Косметический редактор (предмет или F6) меняет имя, волосы, бороду, усы, одежду, бельё и татуировки. Раса, пол, рост, тело, кожа, глаза и созвездие защищены сервером. Вне творческого режима предмет расходуется только после успешного сохранения изменения; отмена и отклонённое сохранение его не расходуют.

`naked false` возвращает декоративную одежду. Броня и её характеристики при этом не меняются. Одежда, нарисованная прямо на собственном скине, является частью этого скина.

У Зеркала преображения и Осколка Демитары свои иконки (`textures/item/appearance_mirror.png` — ручное зеркало в золотой оправе, `demitara_shard.png` — фиолетовый кристалл); раньше они брали ванильные подзорную трубу и осколок аметиста. Зеркало преображения находится во вкладке инструментов творческого режима. Рецепт: два железных слитка, стеклянная панель и две палки по схеме ` IG / SI / S  `, где I — железо, G — стекло, S — палка.

## Редактор

Слева — портрет, расы, прокручиваемое описание со способностями и подрасы. Сверху — «Тип», «Внешность», «Созвездие», подразделы и имя. Справа — настройки. Внизу — поворот, приближение к голове, возврат в полный рост, отмена, сброс текущего раздела и подтверждение. Сброс возвращает значения этого раздела на момент открытия редактора; после смены расы или пола — значения по умолчанию.

Общего фона нет: персонаж показан над живым миром, видимым между окнами. При открытии включается первое лицо и скрывается HUD; при закрытии или отмене возвращаются прежние камера и HUD. На экране подтверждения и во время сохранения модель персонажа скрыта; возврат к редактированию снова её показывает.

Доступны имеющийся или новый скин, Classic/Steve и Slim/Alex, кожа, глаза и их высота, расовые уши, рога и хвосты, рост, грудь, волосы, бороды и усы, гардероб, татуировки и созвездие. Состав и границы параметров определяет раса.

Ползунки поддерживают нажатие и перетаскивание. Персонажа можно вращать мышью; колесо над персонажем приближает к голове, над описанием расы — прокручивает текст. Высота глаз задаётся в пикселях: положительное значение поднимает глаза. Она и цвет глаз применяются к новому скину; имеющийся скин сохраняет своё лицо. Женский шаблон по умолчанию использует Slim, Classic и Slim доступны отдельно.

В полном виде масштаб камеры фиксирован, поэтому выбранный рост виден до подтверждения. Линейка и числовое значение помогают сравнивать размеры.

## Текстуры, модели и анимация

Включены подготовленные пакеты CCC Hairstyles 2.0.1 (13 причёсок), CCC Haircuts 1.0.0 (28 новых, всего 41), CCC Clothing 2.0.0 (13 комплектов, 43 отдельные вещи), CCC Skin Eyes 1.0.0 и обе текстуры нижнего белья. PNG включены без изменений. У каждой вещи и причёски свои основной цвет и до двух каналов декора; «Исходный» восстанавливает авторские цвета. Нижнее бельё имеет исходный вариант и шесть цветовых. Верхний контур глаз связан с основным цветом причёски, а без неё — с палитрой волос.

Порядок слоёв: **кожа → расовые отметки → нижнее бельё → глаза → декоративная одежда → борода/усы → волосы**. Свечение отметок тоже скрывается последующими слоями. Верхняя одежда скрывает верх белья, брюки и юбки — низ, платье — обе части целиком, включая наружный слой скина. Обувь, перчатки и пояс сами по себе бельё не скрывают. В режиме «Нижнее бельё» обе части снова видны.

Волосы, бороды и усы — текстуры скина: пряди на торсе, руках и ногах следуют этим частям тела, отдельная геометрия не создаётся. Наружный слой декоративной одежды не закрывает базовые пряди и длинные бороды; носимая броня может закрывать соответствующие участки.

У альгноров обычные ноги заменяются моделью с бедром, скакательным суставом, плюсной и раздвоенным копытом; верх ноги сохраняет UV одежды. Есть четыре формы ушей, три вида хвоста, пять текстурных бород и пять усов. Существующие формы рогов и их настройки сохранены.

В редакторе зацикленно проигрывается предоставленный `idle.json` (SPEmotes) с отдельными дорожками костей, квадратичной интерполяцией и возвратом к указанному в файле тику. Скорость — половина исходной; между циклами персонаж две секунды удерживает конечную позу. В мире эта анимация не запускается. Поворот всей фигуры не добавляет повторный поворот головы; собственные движения головы из idle остаются. Предпросмотр использует отдельную модель и не меняет ни позу игрока, ни настройки его физики в мире.

Female Gender Mod 3.2.2 необязателен и не включён в JAR: CCC использует установленный мод, его код не встраивается. Если он установлен (и `femaleGenderAdapter` в `civitatum-races.json` включён), грудь везде рисует он, в том числе в редакторе: раньше редактор показывал собственную модель из двух прямоугольных блоков, а в мире была форма FGM. Для фигуры редактора у FGM отдельный набор настроек со значениями редактора; на время её отрисовки он подменяет настройки игрока, а физика этого набора прокручивается редактором и при изменении значения сразу приходит к нему. В редакторе настраиваются все параметры FGM: размер, смещения, ложбинка, одна или две груди, физика, показ и физика в броне, упругость, мягкость и женские звуки урона (новый переключатель в расширенных настройках). Пол FGM — женский у женского персонажа (кроме кованых), иначе мужской. Значения персонажа главнее настроек FGM: когда FGM перезаписывает их своей синхронизацией с сервера, файлом настроек или своим экраном, персонаж записывается снова в следующем кадре. Без FGM грудь рисует собственная модель CCC, как раньше.

## Расы

В каталоге 22 записи, из них 19 игровых рас и подрас. Подробные черты и способности — в [RACES.md](RACES.md). Масштаб влияет на модель, камеру, размеры и досягаемость. Сервер проверяет значения и права редактора, сохраняет персонажа и синхронизирует изменения с наблюдателями.

## Знаки рождения

Тринадцать фигур неба по документу «10b», с ID из Civitatum Starclock. Эффекты, цены и силы — в [RACES.md](RACES.md), откаты — в `BirthsignCatalog.java`.

## Сборка и проверка

Из корня репозитория:

```sh
./gradlew :character-creation:build                # сборка и JUnit
./gradlew :character-creation:runGameTestServer    # игровые тесты способностей и знаков
```

Тесты в `src/test` и `src/gameTest` в JAR не входят.

**Игровые тесты** (`src/gameTest`, NeoForge GameTest) поднимают сервер без окна только с этим модом, гоняют 45 тестов и завершают сборку с ошибкой и списком упавших, если хоть один не прошёл; весь прогон занимает около 20 секунд. Каждый тест строит свою площадку (шаблон `gametest/arena`: пустой объём 32×12×32, пол из камня кладёт сам тест), ставит ночь и нормальную сложность. Игроки входят через серверный список игроков, как с настоящего клиента, но в режиме выживания: встроенный игрок GameTest творческий, неуязвим и не платит за силы. Каждый запуск даёт им новые UUID, потому что мир тестов сохраняется между запусками. Силы с большим радиусом идут в отдельных пакетах (batch), чтобы не задевать соседние тесты.

Проверяются все пассивы и силы 18 рас и 13 знаков, эффекты-расплаты (и после молока), откаты, союзники по команде, жребий и замок знака, команды знака, временные блоки (сохранение мира, устаревшие записи). Совместимость с модами сборки (Spider Overhaul, Hardcore Revival, FTB Teams, Villagers Reborn, Starclock) и всё клиентское (редактор, клавиши, HUD, подсветка, свет) здесь не проверяются: их нет в тестовом сервере или нужен клиент.

## Генерация текстур

Текстуры персонажа и каталоги в `src/main/resources` не правятся руками: их пишут генераторы на Java (`src/tools/java`, в JAR не входят). Вход генераторов лежит в `input/`: исходные скины с PlanetMinecraft и метаданные с ручными настройками.

| Задача | Вход | Результат |
|---|---|---|
| `generateSkin` | `input/skin/` | `textures/character/skin/` |
| `generateEyes` | `input/eyes/` | `textures/character/eyes/` |
| `generateHaircuts` | `input/haircuts/` | `textures/character/haircuts/`, `appearance/haircuts.json` |
| `generateClothing` | `input/clothing/` | `textures/character/clothing/`, `appearance/clothing.json` |
| `generateFacialHair` | `input/facial_hair/` | `textures/character/facial_hair/` |
| `generateTextures` | все сразу | |

Запуск: `./gradlew :character-creation:generateHaircuts` или `main` генератора прямо из IDE (рабочая папка — `character-creation`). Каждый генератор перед записью очищает только свою папку.

Метаданные — JSON рядом с исходниками, с пояснениями в поле `_help`. В них правила, которые раскладывают пиксели скина по цветовым полям, например `"when": "g > r && g > b", "zone": "decor_1"`: правила проверяются по порядку, побеждает первое подходящее. В условиях доступны каналы цвета `r g b`, яркость `lum`, тон и насыщенность `h s v`, положение `x y`, часть тела `group face surface row`.

Все 41 причёска — один набор. У первых 13 (CCC Hairstyles 2.0.1) исходных скинов нет: их источник в `input/haircuts/sources/` — уже подготовленная текстура, а украшения заданы списками цветов. Сведения об авторах — `input/*/CREDITS.md`.

## Языки

Русский и английский — `assets/civitatum/lang/ru_ru.json` и `en_us.json`. Язык выбирает клиент, в том числе для сообщений сервера.

- Тексты рас — ключи `race.civitatum.<id>.name|description|positive|negative|ability|ability_name`; в `races.json` остались только числа и палитры.
- Созвездия — `birthsign.civitatum.<id>.name|description|effect`.
- Подписи каталогов одежды и причёсок генерируются из `input/` по-русски и в каталогах не меняются. Английский берётся из `en_us.json` по ключу `appearance.civitatum.<русский текст>`; без такого ключа подпись показывается как есть. Новую подпись после генерации нужно добавить в `en_us.json`.
- Знак процента в переводе пишется как `%%`: игра форматирует каждую строку. `LangTest` проверяет это и совпадение ключей двух языков.

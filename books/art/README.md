# Open-book reader texture

Runtime asset: `../src/main/resources/assets/civitatum_books/textures/gui/open_book.png`.
The original 1650×953 RGBA PNG is included without resampling. It is drawn with Minecraft's texture sampler.

Created with the built-in image generation tool for Civitatum Books. No lettering or controls are baked into the image; all book text, illustrations and controls are drawn by Java code.

Prompt: a blank open medieval book, perfectly front-on orthographic, crisp low-resolution pixel art for a Minecraft fantasy RPG interface. Two large blank warm ivory parchment pages, matching dimensions, a narrow center gutter, dark brown and muted russet leather cover, stepped corners, subtle stacked paper edges, tan shading near edges and spine. Nearly uniform light page centers for runtime text. Landscape spread approximately 1.73:1, symmetric, limited warm palette, transparent surroundings. No text, page numbers, buttons, symbols, bookmarks, objects, perspective or photographic texture.

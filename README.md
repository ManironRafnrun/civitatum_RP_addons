# Полная нативная история CCC 0.3.0

Архив содержит исходный коммит восстановленной версии 0.2.0, все контрольные точки текущей работы, ветку разработки и теги `ccc/v0.2.0`, `ccc/v0.3.0`. Разделение на части необходимо только для надёжной передачи.

1. Скачайте эту ветку целиком (или клонируйте её).
2. Запустите `python3 restore_history.py` — программа проверит размеры и SHA-256 каждой части и целого bundle.
3. Выполните показанную команду `git clone`. Перейдите на ветку `codex/ccc/development`.

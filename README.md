# Полная нативная история CCC 0.4.0

Включены исходный коммит восстановленной 0.2.0, версии 0.3.0 и 0.4.0, все контрольные точки, ветка разработки и теги `ccc/v0.2.0`, `ccc/v0.3.0`, `ccc/v0.4.0`.

Скачайте эту ветку целиком и запустите `python3 restore_history.py`. Скрипт проверит размеры и SHA-256 каждой части, соберёт bundle и покажет команду восстановления. Затем выполните `git clone CCC-0.4.0-history.bundle CivitatumCharacterCreation` и перейдите на `codex/ccc/development`.

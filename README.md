# Civitatum Couple Interaction (CCI)

Minecraft 1.21.1 / NeoForge. Bridal carrying, animated kisses, hugs and seated shoulder rests. Per-action consent, trusted players, carry-pose preview and configurable obstacle tolerance. Optional PlayerAnimator/bendy-lib integration reuses Emotecraft libraries. Developed by Civitatum Team.

See [README_RU.md](README_RU.md) for installation, controls, configuration and build instructions. Install the mod on both the server and every client.

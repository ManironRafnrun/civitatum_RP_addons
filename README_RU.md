# CCC 0.4.2 — полная исходная Git-история

Все исходные коммиты, предыдущие выпуски, новые резервные снимки и аннотированные метки сохранены. Неизменная история 0.4.1 хранится в base-parts; отдельный небольшой bundle добавляет новые коммиты без повторного хранения прежних файлов.

```sh
python3 restore_history.py /path/to/restored-CCC
```

Скрипт проверяет SHA-256 каждой части, исходной истории и обновления, восстанавливает репозиторий, выполняет fast-forward до ccc/v0.4.2 и сверяет commit/tree. Полностью проверен локальным восстановлением.

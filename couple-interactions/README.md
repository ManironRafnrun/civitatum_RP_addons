# Civitatum Couple Interaction (CCI)

Тестовый выпуск **0.2.0-alpha.1**. Minecraft **1.21.1**, NeoForge **21.1.256+**, Java **21**. Разработчик — **Civitatum Team**.

## Установка

Установите одинаковый JAR CCI на сервер и все клиенты, заменив предыдущую версию. Обязательных сторонних модов нет. Протокол этой версии обновлён: старый клиент CCI к ней не подходит.

Для сгибов в локтях и коленях используются необязательные PlayerAnimator и bendy-lib. Проверен **Emotecraft 2.4.12 для NeoForge 1.21.1**: он уже содержит PlayerAnimator 2.0.1 и bendy-lib 5.1. Если этот Emotecraft установлен, дополнительные копии библиотек не нужны. Без библиотек остаются обычные цельные конечности Minecraft и базовые позы.

## Взаимодействия

- **Нести на руках.** Голова переносимого наклонена вперёд, левая рука отведена от лица несущего. В настройках можно изменить позу и увидеть результат на двух моделях: наклон головы, отведение руки, наклон тела и смещение по трём осям.
- **Поцеловать.** Инициатор подносит правую ладонь к щеке партнёра; оба наклоняются навстречу. Сердечки и звук появляются один раз в момент контакта. Поцелуй доступен и внутри своей пары при переноске.
- **Обнять.** Парная анимация объятий с автоматическим завершением.
- **Сесть рядом.** Игроки садятся рядом, принимающий склоняет голову к плечу инициатора. Отдых продолжается до выхода одного из участников.

Позиции и позы учитывают штатный масштаб обоих игроков, в том числе рост из CCC. Для очень большой разницы роста точное совпадение контактов ограничено длиной конечностей Minecraft. Камера переносимого находится у головы; обзор остаётся независимым.

## Управление

| Действие | По умолчанию |
|---|---|
| Меню действий | Удерживать F9, наведя прицел на игрока |
| Выбрать сектор | Навести курсор и отпустить F9 либо нажать ЛКМ |
| Отмена | Центр круга / Esc / ПКМ |
| Принять / отклонить приглашение | Y / N |
| Завершить взаимодействие | Shift либо сектор выхода в F9 |
| Настройки | F9 без цели либо сектор настроек |
| Добавить игрока в избранные | Сектор со звездой либо вкладка «Избранные» |

Клавиши меняются в категории «Civitatum: взаимодействия». Во время парного действия F9 обращается к текущему партнёру.

## Подтверждения и избранные

Для каждого действия отдельно доступны четыре режима: **спрашивать**, **избранные**, **принимать автоматически**, **запретить**. По умолчанию все действия требуют подтверждения. В режиме «Избранные» запрос от избранного принимается автоматически, от остальных всё ещё требует ответа. Список хранит UUID, включая игроков вне сети. Избранность не отменяет явный запрет конкретного действия.

Сервер проверяет расстояние, видимость и состояние обоих игроков при запросе и при ответе. Чужой игрок не может принять приглашение или разорвать пару. Любой участник может закончить действие без подтверждения другого.

## Препятствия при переноске

В файле мира `serverconfig/civitatum_couple-server.toml`, раздел `[interactions]`:

```toml
carryObstacleMode = "RELAXED"
carryObstacleGraceTicks = 10
carryObstacleTolerance = 0.3
```

| Режим | Поведение |
|---|---|
| `RELAXED` — по умолчанию | Игнорирует низкие блоки, край широкого хитбокса и краткое касание. Позволяет подойти к блоку высотой в один блок и запрыгнуть. Освобождает только при непрерывной помехе верхней центральной части тела. |
| `STRICT` | Прежнее поведение: освобождение при касании полного хитбокса переносимого. |
| `OFF` | Полностью отключает освобождение из-за блоков. |

`carryObstacleGraceTicks` — задержка только мягкого режима (10 тиков = 0,5 секунды). Свободный тик сбрасывает отсчёт. `carryObstacleTolerance` — уменьшение проверяемой области по краям при обычном масштабе игрока. Для полного отключения достаточно поставить `carryObstacleMode = "OFF"`.

Во всех режимах сохраняются обычный выход, реакция на урон, смерть, телепортацию, воду и выход из игры. Настройка не добавляет защиту от падения. Высадка ищет свободное место рядом.

## Остальные настройки и ограничения

Клиентский файл: `config/civitatum_couple-client.toml` — политики запросов, избранные, поза, звук и частицы. Эти же настройки доступны в интерфейсе CCI. Старые запреты переноски и поцелуя учитываются при обновлении.

Серверный файл: `<папка мира>/serverconfig/civitatum_couple-server.toml` — разрешённые действия, дальность (2,5 блока), срок приглашения (12 секунд), интервал запросов (3 секунды), скорость при переноске (80%) и препятствия.

Для начала действия оба должны быть живы, на земле, вне воды, полёта, сна и чужого транспорта. Спринт при переноске отключён. Во время взаимодействий руки заняты: атаки, разрушение блоков и применение предметов блокируются. Поцелуй и объятия завершаются автоматически; Shift позволяет закончить раньше.

## Сборка

Из корня репозитория:

```sh
./gradlew :couple-interactions:build
```

`build` запускает юнит-тесты логики (`src/test`, JUnit 5).

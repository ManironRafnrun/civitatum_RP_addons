# CCC — кожа и глаза 1.0.0

Подготовлены оба предоставленных PNG: основа кожи и отдельный рисунок глаз. Все рабочие файлы — PNG RGBA 64×64. Есть варианты Slim/Alex и Classic/Steve, отдельные слои кожи и глаз, а также готовая объединённая текстура с непересекающимися масками.

| Зона | Что меняется | Настройка |
| --- | --- | --- |
| Кожа | Вся кожа с сохранением светотени | Цвет кожи |
| Радужки | Два цветных пикселя глаз | Цвет глаз |
| Верхний контур | Четыре коричневых пикселя над радужками и белками | Отдельный цвет; можно привязать к цвету волос |
| Белки | Два белых пикселя | Исходный цвет `#F8F8F8`, без перекраски |

Коричневая верхняя линия выделена по исходному рисунку. Она не названа однозначно бровями или ресницами: изображение не позволяет установить это точно. В каталоге указана предложенная привязка к цвету волос; сам редактор этим пакетом не изменяется.

## Структура

Точные пути и настройки находятся в `catalog.asset.json`, палитры — в `palettes.json`.

```text
assets/civitatum/textures/character/
  skin/base_07/<slim или classic>/
    original.png
    neutral.png
    mask_skin.png
  eyes/pmc_eyes/<slim или classic>/
    original.png
    neutral.png
    mask_iris.png
    mask_upper_contour.png
    iris_original.png
    upper_contour_original.png
    sclera_fixed.png
  appearance/base_07_pmc_eyes/<slim или classic>/
    original.png
    neutral.png
    mask_skin.png
    mask_iris.png
    mask_upper_contour.png
    layer_skin_original.png
    layer_iris_original.png
    layer_upper_contour_original.png
    fixed.png
```

В `appearance/` кожа уже объединена с глазами. Маска кожи исключает радужки, верхний контур и белки. Три цветовые маски не пересекаются и вместе с фиксированными белками покрывают всю текстуру. Этот вариант подходит для одной общей операции перекраски.

В `skin/` находится самостоятельная полная основа, включая кожу под глазами. Её маска намеренно покрывает всё базовое тело. При работе отдельными слоями сначала перекрашивайте кожу, затем накладывайте слой из `eyes/`. Не применяйте полную отдельную маску кожи к уже объединённой текстуре: используйте маски из `appearance/`.

Все занятые пиксели расположены на базовой поверхности модели; внешний слой в этих исходниках пустой. Глаза оставлены на исходных координатах без смещения: радужки `(10,13)`, `(13,13)`; белки `(9,13)`, `(14,13)`; верхний контур `(9,12)`, `(10,12)`, `(13,12)`, `(14,12)`. Координаты отсчитываются от нуля.

## Перекраска

У каждого цвета по умолчанию выбран точный исходный вариант. Он сохраняет авторский RGB, не пересчитывая его через нейтральную основу.

```text
result = original
для каждой явно изменённой зоны:
    где mask.alpha > 0:
        result.rgb = round(neutral.rgb * selected_color.rgb / 255)
result.alpha = original.alpha
```

Белки берутся из `fixed.png` и всегда сохраняют исходный цвет. Альфа маски только выбирает пиксели; она не заменяет прозрачность текстуры. Палитры содержат исходный вариант и по шесть примеров оттенков; можно передать произвольный RGB. Эти примеры не назначают цвета конкретным расам CCC.

## Очистка и модели

Из рабочей основы кожи удалены 42 служебных пикселя вне UV модели: восемь образцов оттенков кожи сверху и 34 голубые метки справа. Исходные PNG сохранены без изменения байтов в `sources/`; SHA256 указаны в каталоге.

Исходная кожа имеет разметку Slim. В ней покрыты все 1568 пикселей базовой UV-поверхности. Вариант Classic адаптирует грани рук расширением столбцов `0,1,1,2`; боковые грани сохраняются. В Classic базовая поверхность содержит 1632 пикселя. Голова и глаза для моделей одинаковы. Маски объединённой кожи покрывают соответственно 1560 и 1624 пикселя, исключая восемь пикселей рисунка глаз.

## Проверка и подключение

`CCC_Skin_Eyes_Preview.png` показывает исходную кожу, кожу с глазами, карту областей и смену каждого цвета по отдельности. На карте голубой — кожа, розовый — радужки, зелёный — верхний контур, белый — белки.

`VERIFICATION.json` содержит результаты проверки исходных файлов, очистки, покрытия обеих моделей, сохранения альфы, сборки из слоёв и 36 применений цветов по одной зоне. Белки защищены во всех вариантах. Превью собрано напрямую из UV.

Это пакет ассетов. Подключение к редактору CCC и проверка внутри Minecraft не выполнялись. При подключении нужно использовать подготовленный слой глаз вместо прежнего рисунка глаз, чтобы не отрисовывать оба варианта одновременно. Кожу и глаза следует собирать перед наложением одежды и причёсок.

## Повторная подготовка

Требуются Python 3, NumPy и Pillow. Для превью используется DejaVu Sans; при необходимости измените путь `FONT` в скрипте.

```bash
python tools/prepare_skin_eyes.py --skin sources/Slim-Arm-Base-Skin-7-on-planetminecraft-com.png --eyes sources/pmcskin3d-steve.png --output rebuilt
python tools/verify_skin_eyes.py rebuilt
```

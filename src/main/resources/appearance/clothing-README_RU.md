# CCC — одежда, пакет 2.0.0

Заново подготовлены 7 женских и 6 мужских комплектов: 43 видимые составляющие, до трёх независимых цветовых полей на каждый предмет. Все рабочие текстуры — PNG RGBA 64×64, в вариантах Slim/Alex и Classic/Steve.

## Цветовые поля

| Поле | Назначение |
| --- | --- |
| Цвет одежды (`main`) | Основной материал выбранного предмета |
| Цвет декораций 1 (`decor_1`) | Первая контрастная часть, вставка или отделка |
| Цвет декораций 2 (`decor_2`) | Вторая отдельная часть, если она есть |

Три поля относятся к выбранному предмету. У брюк, пояса и обуви собственный основной цвет. Полный костюм — набор таких предметов. Неиспользуемые поля перечислены в `disabled_controls`; соответствующих пустых PNG нет. В меню редактора эти поля следует скрыть или отключить.

| Пример | Цвет одежды | Цвет декораций 1 | Цвет декораций 2 |
| --- | --- | --- | --- |
| Gambeson / гамбезон | Основные стёганые панели | Фиолетовая контрастная ткань | Не требуется |
| Verer Daelaf / платье | Синяя ткань платья | Красный центральный элемент | Зелёный плащ |
| Northern Warmth / кафтан | Основная ткань | Красные вставки | Кайма и обшивка |
| Striped Shirt / рубаха | Красные полосы | Светлые полосы | Ворот и ремешки рукавов |

Полная таблица всех 43 составляющих находится в `COLOR_MAPPING_RU.md`. Золотистая отделка и тёмный ворот Verer остаются защищёнными. У Gambeson кожа ворота и пуговицы также сохраняют исходный цвет, чтобы у самого гамбезона оставалось ровно два цветовых поля.

Белые блузки Aegipants, Ladylike и Pumpkin Field выделены отдельно. Смена цвета бриджей или юбки сохраняет блузку белой. Бант Aegipants остаётся красным, пока пользователь явно не изменит `decor_1` самой блузки. Корсет Mistress Arrives целиком отделён от платья, включая тёмные кожаные пиксели.

Палитра Sunset содержит более насыщенные оттенки; для юбки Pumpkin Field выбраны спокойные природные цвета. У каждого активного поля есть вариант «Исходный» и пять примеров оттенков. Можно передать и произвольный RGB.

## Файлы предмета

Пути перечислены в `catalog.asset.json`:

```text
assets/civitatum/textures/character/clothing_v2/
  female/ или male/
    <комплект>/
      slim/ или classic/
        outfit_original.png
        <предмет>/
          original.png
          neutral.png
          fixed.png
          mask_main.png
          mask_decor_1.png       # только если нужен
          mask_decor_2.png       # только если нужен
          layer_main_original.png
          layer_decor_1_original.png
          layer_decor_2_original.png
          base_surface.png
          outer_surface.png
```

- `original.png` — видимые пиксели предмета в точных исходных цветах.
- `neutral.png` — нейтральная основа для перекраски, с сохранённой светотенью и альфой. Защищённые детали сохраняют исходный RGB.
- `mask_*.png` — белые бинарные маски. Маски разных цветов и разных предметов не пересекаются.
- `fixed.png` — исходные пиксели защищённых деталей; при их отсутствии полностью прозрачный.
- `layer_*_original.png` — исходные цвета отдельно для соответствующей маски.
- `base_surface.png` и `outer_surface.png` — исходные цвета на базовой и внешней поверхностях модели. Их нельзя использовать как нейтральную основу.
- `outfit_original.png` — весь комплект в исходных цветах после очистки служебных пикселей вне UV одежды.

Оригинальные исходники сохранены без изменения байтов в `sources/`. Их SHA256 находятся в каталоге. В рабочих текстурах удалены только пиксели вне UV одежды: 38 у Aegipants, 48 у Gambeson, 33 у Tunic Grey. Значения альфы внутри UV сохранены, включая полупрозрачные пиксели.

## Перекраска и точный исходный цвет

Начинайте с `original.png`. У каждого поля по умолчанию выбран `mode: original`: его пиксели остаются без изменений. Перекрашивайте только поля, для которых пользователь выбрал другой цвет:

```text
result = original
для каждого явно изменённого поля:
    где mask.alpha > 0:
        result.rgb = round(neutral.rgb * selected_color.rgb / 255)
result.alpha = original.alpha
```

Маска выбирает пиксели; её альфа не заменяет и не умножает альфу одежды. Поле в режиме «Исходный» нельзя восстанавливать умножением нейтральной основы на опорный цвет: это не гарантирует точный авторский RGB. Неизменённые поля берутся прямо из исходника.

При сборке комплекта каждый предмет обрабатывается отдельно. Затем его пиксели помещаются в общую текстуру на тех же координатах. Для отображения базовой и внешней поверхностей используйте соответствующие UV и фильтрацию nearest без сглаживания.

## Границы разделения и адаптации

Выделены видимые фрагменты плоских текстур. Ткань, скрытая под корсетами, поясами и другими деталями, в исходниках отсутствует и здесь не дорисована. Все части точно восстанавливают исходный костюм, но снятие перекрывающей детали может открыть прозрачный участок. В каталоге это отмечено `visible_fragment: true` и `hidden_cloth_reconstructed: false`.

Женские исходники и Striped Shirt имеют разметку Slim, остальные мужские — Classic. Адаптация затрагивает грани рук: Slim → Classic дублирует центральный столбец (`0,1,1,2`), Classic → Slim опускает один столбец (`0,2,3`). Боковые грани глубиной четыре пикселя сохраняются. На исходной модели рисунок сохранён точно; вариант с другой шириной рук требует просмотра в игре.

## Просмотр и проверка

- `CCC_Female_Color_Controls.png` и `CCC_Male_Color_Controls.png` показывают основной предмет каждого комплекта: исходник, карту масок и смену каждого цвета по отдельности.
- `CCC_Female_Components.png` и `CCC_Male_Components.png` показывают все 43 составляющие и их маски спереди и сзади.
- На картах голубой означает основной цвет, розовый — декор 1, зелёный — декор 2; серые детали не меняются при редактировании показанного поля.
- `VALIDATION.json` содержит проверки сборки; `VERIFICATION.json` — результаты отдельной проверки экспортированных файлов, включая 680 применений цветов по одному полю.

Проверены исходные SHA256, UV и адаптация рук, отсутствие пересечений, полное покрытие, восстановление костюмов, защищённые детали, альфа и независимость всех палитр. Превью используют плоские виды спереди и сзади; это не скриншоты из игры.

Это пакет подготовленных ассетов со схемой `ccc-clothing-three-controls-v2`. Для подключения к CCC нужен загрузчик этой схемы и привязка полей меню. Пакет не добавляет пункты в редактор автоматически; проверка внутри Minecraft не выполнялась.

## Повторная сборка

В `tools/` находятся скрипты подготовки и отдельной проверки. Требуются Python 3, NumPy и Pillow. Для превью используется DejaVu Sans; при необходимости измените путь `FONT` в скрипте.

```bash
python tools/prepare_clothing_v2.py --sources sources --output rebuilt
python tools/verify_clothing_v2.py rebuilt
```

# CCC — причёски 2.0.1

Переработаны все 13 предоставленных причёсок по тому же принципу, что и одежда: до трёх независимых цветовых полей на причёску. Всего 23 активные зоны, каждая в вариантах Slim/Alex и Classic/Steve. Рабочие текстуры — PNG RGBA 64×64.

## Назначение полей

| Поле | Назначение |
| --- | --- |
| Цвет волос (`main`) | Основная масса волос |
| Цвет декораций 1 (`decor_1`) | Бант, завязка, вставки; у Ombre + Wreath — мелирование |
| Цвет декораций 2 (`decor_2`) | Вторая отдельная деталь, если нужна |

| Причёска | Цвет волос | Декорации 1 | Декорации 2 |
| --- | --- | --- | --- |
| Black Long Hair, Pumpkin Spice, Shaggy Hooligan, Steve Weird Hair | Все волосы | Не требуется | Не требуется |
| Candied Love, Blond 12-1, Blond 16-1, Black Base 2, Loose Plat | Волосы | Завязки | Не требуется |
| Hair Base 1-2 | Волосы | Розовый бант | Не требуется |
| Long Auburn | Волосы | Розовые декоративные вставки | Не требуется |
| Ombre + Wreath | Основной цвет волос | Мелирование и светлые концы | Весь венок |
| Ponytail Streak | Все волосы, включая передние пряди | Золотистая завязка | Не требуется |

Полная таблица с отдельной строкой для каждой причёски — `COLOR_MAPPING_RU.md`. Неиспользуемые поля указаны в `disabled_controls`: редактор должен их скрыть или отключить. Пустые маски этих полей не создаются.

У Ombre + Wreath (12) основной цвет волос и мелирование имеют отдельные маски. Золотистые светлые участки и концы отнесены к мелированию, коричневая основа и переходные оттенки — к основному цвету. Третье поле меняет весь венок: лепестки, листву и сердцевины. По умолчанию венок сохраняет все исходные цвета.

У Ponytail Streak (13) передние волосы, собранные назад в хвост, входят в основной цвет вместе с остальными волосами. Отдельно меняется только золотистая завязка — через «Декорации 1». Поле «Декорации 2» не требуется.

Розовые элементы Long Auburn интерпретированы как декоративные вставки по рисунку; их точный материал не установлен.

## Что изменилось относительно 1.0.0

- У каждой причёски теперь не более трёх полей с едиными именами, как у нового пакета одежды.
- Все управляющие маски бинарные и не пересекаются. Градиентные перекрывающиеся маски старого пакета не используются.
- Светотень и переход яркости хранятся в нейтральной текстуре. Цвета разных зон применяются независимо.
- У каждого поля есть точный режим «Исходный». Изменение волос оставляет невыбранные украшения в исходных цветах, и наоборот.

Палитра волос включает исходную окраску и шесть примеров: чёрный, каштановый, красно-каштановый, рыжий, блонд, серебристый. У декора собственные палитры; доступен и произвольный RGB. У венка и завязок собственные цвета декора.

## Файлы и перекраска

Пути моделей, текстур и масок перечислены в `catalog.asset.json`, палитры — в `palettes.json`.

```text
assets/civitatum/textures/character/hair_v2/
  <причёска>/
    slim/ или classic/
      original.png
      neutral.png
      fixed.png
      mask_main.png
      mask_decor_1.png          # при необходимости
      mask_decor_2.png          # при необходимости
      layer_main_original.png
      layer_decor_1_original.png
      layer_decor_2_original.png
      hair_original.png
      decor_original.png       # при наличии украшений
      base_surface.png
      outer_surface.png
```

`original.png` сохраняет точный RGB и альфу всех оставленных исходных пикселей. `neutral.png` содержит серую основу перекрашиваемых зон, с их исходной светотенью. `fixed.png` оставлен как общий технический файл и в этом пакете полностью прозрачный: все видимые пиксели относятся к одному из активных цветовых полей. `layer_*_original.png` хранит исходный цвет отдельно по каждой маске.

`hair_original.png` и `decor_original.png` разделяют видимые волосы и украшения. Мелирование Ombre и передние пряди Ponytail входят в волосы, а весь венок и завязки — в украшения. `base_surface.png` и `outer_surface.png` разделяют исходные цвета по поверхностям модели, а не задают цветовые поля.

Для перекраски начинайте с исходника и изменяйте только выбранные поля:

```text
result = original
для каждого явно изменённого поля:
    где mask.alpha > 0:
        result.rgb = round(neutral.rgb * selected_color.rgb / 255)
result.alpha = original.alpha
```

Маска только выбирает пиксели. Её альфа не заменяет и не умножает прозрачность волос. Режим `original` берёт точный RGB из исходника; его нельзя заменять умножением нейтральной основы на опорный цвет. Порядок применения цветов не влияет на результат, поскольку маски не пересекаются.

У Black Long Hair в исходнике есть 64 полностью чёрных пикселя. Для их перекраски минимальная яркость нейтральной основы поднята до 64. Исходный чёрный вариант сохранён без изменений.

## Исходники, UV и подключение

Исходные PNG сохранены без изменения байтов в `sources/`; SHA256 указаны в каталоге. У Shaggy Hooligan из рабочих файлов удалены те же 100 служебных пикселей и меток шаблона, что в предыдущем пакете. Остальные причёски сохраняют все занятые исходные пиксели.

У Long Auburn есть десять пикселей прядей на руках. Для них сохранена прежняя интерпретация Slim-разметки по расположению фрагментов; исходная модель автора не подтверждена. Classic расширяет соответствующие грани рук столбцами `0,1,1,2`. У остальных причёсок рабочие текстуры не занимают UV рук и одинаковы для двух моделей. Long Auburn требуется проверить на модели внутри игры.

Длинные пряди нарисованы на стандартных UV головы, торса, рук и ног и двигаются вместе с ними. Отдельная геометрия волос не создавалась. Для отображения поверх одежды нужно согласовать базовые и внешние поверхности либо использовать отдельный проход отрисовки. Фильтрация — nearest, без сглаживания.

Украшения выделены из плоских исходников. Волосы, закрытые украшением, не дорисованы: изменение цвета полностью поддерживается, а снятие украшения может открыть прозрачный участок. В каталоге это отмечено `hidden_hair_reconstructed: false`.

Это подготовленные ассеты со схемой `ccc-hair-three-controls-v2`. Для работы в CCC нужен загрузчик этой схемы и привязка трёх полей меню. Старое смешивание весов `normalized_weights_255` для этого пакета не применяется. Установка пакета сама по себе не добавляет причёски в редактор. Проверка внутри Minecraft не выполнялась.

## Превью и проверка

- `CCC_Hair_Color_Controls.png` — все 13 причёсок: исходник, карта масок, смена каждого поля по отдельности, спереди и сзади.
- `CCC_Hairstyles_Preview.png` — исходные варианты и три примера сочетания цветов.
- На картах голубой — волосы, розовый — декор 1, зелёный — декор 2, серый — защищённые детали.
- `VALIDATION.json` — проверки при сборке, `VERIFICATION.json` — отдельная проверка экспортированных файлов.

Проверены исходные SHA256 и цвета, UV, разметка рук, отсутствие пересечений и пустых управляющих масок, полное покрытие, сохранение альфы, защищённые детали, восстановление из отдельных слоёв и независимость порядка перекраски. Все 258 применений цветов по одному полю проходят проверку. Превью получены из UV и не являются скриншотами игры.

Для повторной подготовки требуются Python 3, NumPy и Pillow. В скрипте превью используется DejaVu Sans; в другой системе измените путь `FONT`.

```bash
python tools/prepare_hair_v2.py --sources sources --output rebuilt
python tools/verify_hair_v2.py rebuilt
```
